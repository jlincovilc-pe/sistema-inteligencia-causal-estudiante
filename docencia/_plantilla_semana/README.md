# Plantilla para ejemplos semanales

Copia esta estructura para iniciar un nuevo bloque docente. Reemplaza `SXX_SYY_tema`
por las sesiones y el tema correspondientes.

```text
SXX_SYY_tema/
├── PLAN.md
├── sesion1_<verbo>.ipynb
├── sesion2_<verbo>.ipynb
├── NOTAS_PROFESOR.md
├── RESULTADOS.md
├── recursos/
└── recomendaciones/
```

Incluye un segundo notebook solo cuando el bloque tenga una segunda sesión
práctica. `recursos/` y `recomendaciones/` son opcionales. Mantén una sola copia
editable de cada notebook; guarda sus salidas en esa misma copia cuando ayuden
a preparar la clase. En el
plan identifica capítulo, sesión, componente o notebook del repositorio usado
como base, producto esperado, datos, dependencias y contingencias. Distingue
resultados medidos de valores conocidos por construcción.

El plan general del curso y el sílabo siguen siendo las fuentes canónicas de
calendario, evaluación y secuencia curricular.
